# МДК 05.02
Разработка кода информационной системы

Репозиторий с лабораторными и домашними контрольными работами по МДК 05.02.
Задания выполнены на языке Pascal в среде разработки Lazarus.

## Структура репозитория
- LR — лабораторные работы
  - LR_Pas — лабораторные работы, выполненные на ЯП Pascal
  - LR_Laz — лабораторные работы, выполненные в среде разработки Lazarus
- DKR — домашние контрольные работы

## Используемые технологии
- Язык программирования: Pascal
- Среда разработки: Lazarus
